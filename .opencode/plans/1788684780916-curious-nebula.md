## Risiko

- VPS mati saat SSH putus: systemd `Restart=always` untuk 3 modul + gateway
  OpenClaw bawaan (kini jalan manual).
- Skill tanpa auth di port publik: batasi via firewall hanya untuk IP yang perlu.
- `NODE_ENV=production` global merusak build: selalu `env -u NODE_ENV`.
- Laptop panas: `nice -n 19`, batasi thread, build secukupnya.
- Jangan commit otomatis, pemilik repo yang commit dan push.
